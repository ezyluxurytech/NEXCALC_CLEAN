# NexCalc

A compact, responsive calculator built with plain HTML, CSS, and JavaScript. It supports addition, subtraction, multiplication, division, parentheses, and sine, cosine, and tangent in degrees or radians.

## Run

Open `index.html` in a browser, or serve this folder with a local static web server.

## Files

- `index.html` contains the calculator page.
- `css/style.css` contains its layout and responsive styling.
- `js/app.js` handles keypad input, keyboard input, angle mode, and safe expression parsing.

The calculator does not use `eval()` or external libraries. Enter trig functions with parentheses, such as `sin(30)` in degree mode.
